**근거**

## 2. 실험 설계

|           |                      |
| --------- | -------------------- |
| 대조군(A) |                      |
| 실험군(B) |                      |
| 배정 비율 | 50:50                |
| 배정 단위 | 사용자 / 세션 / 기기 |
| 대상      | (전체 / 특정 조건)   |

**배정 단위를 사용자로 두는 이유**: 세션 단위로 배정하면 같은
사용자가 A와 B를 번갈아 보게 되어 처치가 섞인다.

## 3. 지표

**주 지표 (Primary)**

| 지표 | 정의 | 현재 값 |
| ---- | ---- | ------- |
|      |      |         |

주 지표는 **하나**로 정한다. 여러 개를 두면 그중 하나가 우연히
유의해질 확률이 올라간다.

**보조 지표 (Secondary)**

| 지표 | 정의 |
| ---- | ---- |
|      |      |

판단 근거로 쓰지 않는다. 해석을 돕는 용도다.

**가드레일 지표 (Guardrail)**

| 지표 | 허용 범위 |
| ---- | --------- |
|      |           |

주 지표가 개선되어도 가드레일이 무너지면 배포하지 않는다.
(예: 전환율은 올랐는데 이탈률이 급증한 경우)

## 4. 표본수와 기간

```python
from abtest_lab.power import sample_size

sample_size(p_base=___, mde=___)
```

|                       |      |
| --------------------- | ---- |
| 기준선(p_base)        |      |
| 감지 목표(MDE)        |      |
| 유의수준(alpha)       | 0.05 |
| 검정력(power)         | 0.8  |
| **필요 표본(그룹당)** |      |
| 일 트래픽(그룹당)     |      |
| **필요 기간**         | 일   |

**MDE를 이 값으로 정한 이유**

(비즈니스적으로 의미 있는 최소 개선폭. 임의로 정하면 안 된다)

**기간은 7의 배수로 맞춘다.** 요일별 사용자 구성이 다르므로
특정 요일이 더 많이 포함되면 결과가 왜곡된다.

## 7. 분석 전 점검

판단일에 다음을 순서대로 확인한다. **하나라도 통과하지 못하면
전환율 비교를 하지 않는다.**

**① SRM 체크**

```python
from abtest_lab.diagnostics import check_srm

check_srm([A그룹_인원, B그룹_인원], expected_ratio=[0.5, 0.5])
```

`srm=True`면 실험 결과를 폐기한다. 보정하지 않는다.

**② 결측률 비교**

그룹별·기기별 결측률이 크게 다르면 추적 문제를 의심한다.
결측이 한쪽에 몰려 있으면 비교 자체가 무효다.

**③ 기간별 추이**

날짜별 지표를 그려 초기에만 차이가 나타나는지 확인한다.
초기 효과(novelty effect)라면 전체 평균이 왜곡된다.

---

## 8. 판정 기준

```python
from abtest_lab.testing import ztest_p, ztest_ci

ztest_p(n_a, n_b, conv_a, conv_b)
ztest_ci(n_a, n_b, conv_a, conv_b)
```

| 조건                        | 결정                                           |
| --------------------------- | ---------------------------------------------- |
| p < 0.05 이고 가드레일 정상 | 배포                                           |
| p >= 0.05                   | 기각. 신뢰구간 폭을 근거로 표본 추가 여부 판단 |
| 가드레일 위반               | 주 지표와 무관하게 배포하지 않음               |

**보고 시 함께 적는다**: 효과 크기, 신뢰구간, 표본 수, p값.
p값 단독으로 보고하지 않는다.

## 9. 중단 조건

다음 상황에서는 판단일 전에 실험을 중단한다.

- 가드레일 지표가 허용 범위를 벗어남
- 오류율 급증 등 명백한 장애
- SRM이 지속적으로 관측됨

**"결과가 좋아서" 또는 "결과가 나빠서"는 중단 사유가 아니다.**
