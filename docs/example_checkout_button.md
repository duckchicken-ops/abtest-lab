# 실험 설계 문서 — 결제 버튼 문구 변경

> [실험 설계 템플릿](experiment_design_template.md)을 채운 예시 문서.
> 실제 서비스 데이터가 아니라 템플릿 사용법을 보이기 위한 가상 사례다.

|           |                                |
| --------- | ------------------------------ |
| 작성자    | (담당자)                       |
| 작성일    | 2026-08-24                     |
| 실험 기간 | 2026-09-01 ~ 2026-09-14 (14일) |
| 상태      | 종료                           |

---

## 1. 배경과 가설

**현재 상황**

퍼널 분석 결과 장바구니에서 결제 완료로 넘어가는 구간의 전환율이
12.0%로, 앞 단계 대비 이탈이 가장 큰 구간이다.

| 단계          | 인원      | 직전 단계 대비 |
| ------------- | --------- | -------------- |
| 상품 조회     | 100,000   | —              |
| 장바구니 담기 | 31,200    | 31.2%          |
| 결제 진입     | 12,000    | 38.5%          |
| **결제 완료** | **1,440** | **12.0%**      |

**가설**

결제 버튼 문구 "구매하기"가 최종 결제라는 점을 명확히 전달하지
못해 사용자가 다음 단계를 확인하려다 이탈한다. "지금 주문"으로
바꾸면 행동이 명확해져 결제 완료 전환율이 오를 것이다.

**근거**

- 사용자 인터뷰(n=12) 중 4명이 "누르면 바로 결제되는지 몰랐다"고 응답
- 2026-05 문구 실험에서 장바구니 버튼을 "담기"에서 "장바구니에 넣기"로
  변경했을 때 해당 단계 전환율이 2.1%p 상승한 선례가 있음

---

## 2. 실험 설계

|           |                                       |
| --------- | ------------------------------------- |
| 대조군(A) | 기존 문구 "구매하기"                  |
| 실험군(B) | 변경 문구 "지금 주문"                 |
| 배정 비율 | 50:50                                 |
| 배정 단위 | 사용자                                |
| 대상      | 결제 진입 페이지에 도달한 전체 사용자 |

**배정 단위를 사용자로 두는 이유**: 세션 단위로 배정하면 같은
사용자가 재방문 시 다른 문구를 보게 되어 처치가 섞인다.
결제는 여러 세션에 걸쳐 고민하는 경우가 많아 특히 문제가 된다.

---

## 3. 지표

**주 지표 (Primary)**

| 지표             | 정의                                 | 현재 값 |
| ---------------- | ------------------------------------ | ------- |
| 결제 완료 전환율 | 결제 진입 사용자 중 결제 완료한 비율 | 12.0%   |

**보조 지표 (Secondary)**

| 지표                 | 정의                                 |
| -------------------- | ------------------------------------ |
| 결제 페이지 체류시간 | 진입부터 이탈 또는 완료까지의 시간   |
| 결제 시도 후 실패율  | 결제를 시도했으나 완료되지 않은 비율 |

판단 근거로 쓰지 않는다. 전환율이 올랐다면 체류시간이 줄었는지를
함께 보아 "명확해져서"라는 가설과 일치하는지 확인하는 용도다.

**가드레일 지표 (Guardrail)**

| 지표        | 허용 범위                  |
| ----------- | -------------------------- |
| 주문 취소율 | 현재 2.1% 대비 +0.5%p 이내 |
| 결제 오류율 | 현재 0.8% 대비 +0.2%p 이내 |

주문 취소율을 가드레일로 두는 이유: 문구가 결제를 서두르게 만들어
전환은 올랐으나 이후 취소가 늘어나는 경우, 실질적 개선이 아니다.

## 4. 표본수와 기간

```python
from abtest_lab.power import sample_size

sample_size(p_base=0.12, mde=0.03)
# 2036
```

|                       |                           |
| --------------------- | ------------------------- |
| 기준선(p_base)        | 0.12                      |
| 감지 목표(MDE)        | 0.03 (3%p)                |
| 유의수준(alpha)       | 0.05                      |
| 검정력(power)         | 0.8                       |
| **필요 표본(그룹당)** | **2,036명**               |
| 일 트래픽(그룹당)     | 약 200명                  |
| **필요 기간**         | 약 10일 → **14일로 설정** |

**MDE를 3%p로 정한 이유**

12.0% → 15.0%는 월 결제 건수 기준 약 360건 증가에 해당한다.
개발·QA 공수를 고려할 때 이보다 작은 개선은 배포 가치가 낮다는
판단으로 팀과 합의했다.

참고로 1.5%p를 감지하려면 그룹당 7,761명이 필요하다.
현재 트래픽으로는 39일이 걸려 실험 기간으로 적절하지 않다.

```python
sample_size(p_base=0.12, mde=0.015)
# 7761
```

**기간을 14일로 잡은 이유**

필요 기간은 10일이지만 7의 배수로 맞춰 14일로 설정했다.
요일별 사용자 구성이 다르므로 특정 요일이 더 많이 포함되면
결과가 왜곡된다. 10일이면 4개 요일이 두 번씩 포함된다.

## 5. 판단 시점

|           |                                             |
| --------- | ------------------------------------------- |
| 판단일    | 2026-09-15                                  |
| 중간 확인 | 매일. 모니터링만 하며 승패 판단은 하지 않음 |

**순차검정 적용 여부: 미적용**

14일간 매일 확인할 예정이나, 조기 종료 계획이 없으므로
순차검정 경계를 적용하지 않는다. 중간 확인은 가드레일 지표와
SRM 감시 목적이며, 주 지표를 근거로 어떤 결정도 하지 않는다.

> 참고: 조기 종료가 필요했다면 다음과 같이 시점별 경계를 산출한다.

> sequential_boundaries(n_peeks=14)
> ```
>
> 14회 확인 기준 검정력 손실은 94.4% → 80.6%로 작지 않다.
> 조기 종료의 이득이 확실할 때만 채택한다.

## 6. 사전 지정 세그먼트

| 세그먼트           | 지정 이유                                                     |
| ------------------ | ------------------------------------------------------------- |
| 신규 / 기존 구매자 | 기존 구매자는 결제 흐름에 익숙해 문구 영향이 작을 것으로 예상 |
| 모바일 / 데스크톱  | 모바일은 버튼 크기 제약으로 문구 노출 방식이 다름             |

**여기 적히지 않은 세그먼트 분석은 탐색적이며, 발견이 아니라
가설로 취급한다.**

다중검정 보정: BH (`method="fdr_bh"`), alpha=0.05

세그먼트 2종 × 2수준 = 4개 조합을 확인한다. 보정 없이 4개를 보면
실제 차이가 없어도 하나 이상 유의할 확률이 약 18%다.

## 7. 분석 전 점검

판단일에 다음을 순서대로 확인한다.
**하나라도 통과하지 못하면 전환율 비교를 하지 않는다.**

**① SRM 체크**

```python
from abtest_lab.diagnostics import check_srm

check_srm([2812, 2794], expected_ratio=[0.5, 0.5])
# {'p_value': 0.8105, 'srm': False, ...}
```

통과. p값 0.81로 배정 비율이 의도와 일치한다.

**② 결측률 비교**

| 그룹 | 배정  | 전환 기록 있음 | 결측률 |
| ---- | ----- | -------------- | ------ |
| A    | 2,812 | 2,798          | 0.50%  |
| B    | 2,794 | 2,781          | 0.47%  |

통과. 그룹 간 결측률 차이가 0.03%p로 무시할 수준이다.

기기별로도 확인했으며 모바일 0.6%, 데스크톱 0.4%로 차이가 없다.

**③ 기간별 추이**

일별 전환율을 확인한 결과 실험 첫 3일과 이후 기간의 그룹 간
차이가 각각 1.9%p, 2.2%p로 일관됐다. 초기에만 나타나는
효과(novelty effect)가 아니다.

---

## 8. 판정 기준

| 조건                        | 결정                                           |
| --------------------------- | ---------------------------------------------- |
| p < 0.05 이고 가드레일 정상 | 배포                                           |
| p >= 0.05                   | 기각. 신뢰구간 폭을 근거로 표본 추가 여부 판단 |
| 가드레일 위반               | 주 지표와 무관하게 배포하지 않음               |

## 9. 중단 조건

- 주문 취소율이 2.6%를 초과
- 결제 오류율이 1.0%를 초과

## 10. 결과

```python
from abtest_lab.testing import ztest_p, ztest_ci

ztest_p(2798, 2781, 341, 400)
# (-2.339, 0.0193)

ztest_ci(2798, 2781, 341, 400)
# (-0.0392, -0.0035)
```

|        | A (구매하기) | B (지금 주문) |
| ------ | ------------ | ------------- |
| 인원   | 2,798        | 2,781         |
| 전환   | 341          | 400           |
| 전환율 | 12.19%       | 14.38%        |

**차이**: +2.19%p (95% CI: +0.35%p ~ +3.92%p)
**p값**: 0.0193
**상대 개선**: 약 18%

**가드레일**

| 지표        | A    | B    | 판정          |
| ----------- | ---- | ---- | ------------- |
| 주문 취소율 | 2.1% | 2.3% | 정상 (+0.2%p) |
| 결제 오류율 | 0.8% | 0.8% | 정상          |

**사전 지정 세그먼트** (BH 보정 후)

| 세그먼트    | 차이   | 보정 p값 | 유의 |
| ----------- | ------ | -------- | ---- |
| 신규 구매자 | +3.4%p | 0.031    | O    |
| 기존 구매자 | +0.9%p | 0.412    | X    |
| 모바일      | +2.6%p | 0.048    | O    |
| 데스크톱    | +1.5%p | 0.412    | X    |

**결정: 배포**

주 지표가 유의하게 개선되었고 가드레일이 모두 정상 범위다.

**배운 것**

1. 신규 구매자에서 효과가 크고 기존 구매자에서 작았다.
   결제 흐름에 익숙한 사용자는 문구 영향이 작을 것이라는
   사전 예상과 일치한다.

2. 신뢰구간이 +0.35%p ~ +3.92%p로 넓다. 목표했던 3%p 개선인지는
   이 데이터로 확정할 수 없다. 점추정 2.19%p를 그대로 믿기보다
   "0.35%p 이상 개선"으로 보수적으로 해석하는 것이 안전하다.

3. 실험 종료 후 탐색적으로 확인한 결과 20대 사용자에서 차이가
   가장 컸으나(+4.8%p), 사전 지정하지 않은 세그먼트이므로
   발견이 아닌 가설로 기록한다. 연령대를 사전 지정한 후속 실험이
   필요하다.
